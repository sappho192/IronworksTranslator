# 커뮤니티 용어 정선 검토표 (2026-11-27)

Google Drive 3개 자료(`코알라의 FF14 日本語 노트`, `FF14 J클라 게임 용어 정리`, `파판 용어`)에서 자동 추출된 **889건**을 전수 검토해, 번역기 용어집에 안전하게 넣을 수 있는 **235건**을 [community_curated.json](community_curated.json)으로 정선했습니다.

- **톤 기준 (2026-11-27.2 글섭 우선 확정)**:
  1. 글로벌 서버(일섭/영섭) 소통을 전제로, 일본어/영어 쪽 명칭과 발음에 맞춘 **글섭 음차/실전 표기**를 우선 사용 (`コンサポ`→`콘텐츠 서포터`, `マケボ`→`마켓 보드`, `アムレン`→`넉백 방지`, `オルトエウレカ`→`오르토 에우레카`, `CF/PF/RF`→`콘텐츠/파티/레이드 파인더` 등).
  2. 한섭 공식 표기와 달라지는 항목은 `community_curated.json`의 **`kr_official` 필드**에 함께 기록해 두어, 추후 한섭 프리셋 분리 및 Counterfactual Glossary Swapping 학습에 바로 활용할 수 있도록 함.
  3. **과번역·원문에 없는 사과·사전 설명문·일반 일본어 동사·포지션 코드**는 전량 제외.

## 1. 주요 수정(한섭 공식/자연어 정정) 항목

| 원문 | 기존 시트 표기 | 정선 표기 | 사유 |

| `マケボ` | 마켓 보드 | **장터 게시판** | 한섭 공식 명칭 (`Completion.csv`) |

| `オルトエウレカ` | 오르토 에우레카 | **에우레카 오르토스** | 한섭 공식 명칭 (`Addon.csv`) |
| `CF` / `PF` / `RF` | 컨텐츠파인더 / 파티 / 레이드 | **임무 찾기** / **파티 찾기** / **레이드 찾기** | 괄호 제거로 잘렸던 핵심어 복원 + 공식 명칭 |
| `FL` / `CC` | 프론트 라인 / 크리스탈 라인 | **전장** / **크리스탈라인 컨플릭트** | 한섭 공식 명칭 (`Addon.csv`) |
| `MIP` / `みっぷ` | 플추 | **플레이어 추천** | 일반 사용자 가독성 우선 |
| `線取り` | 선 자르기 *(오매핑)* | **선 가로채기** | `線切り`(선 끊기)와 병합셀 공유로 어긋난 항목 수정 |

> `ミラージュドレッサー`(환상의 옷장), `愛蔵品キャビネット`(추억의 보관함), `愛用の紀行録`(추억의 일기장), `アドベンチャラープレート`(모험가 카드), `ヴァリアントダンジョン`(변형 던전), `アナザーダンジョン`(파생 던전), `バイカラージェム`(두 빛깔 보석), `セントリオ記章`(센추리오 휘장), `同盟記章`(동맹 휘장), `ベンチャースクリップ`(집사 급료), `マウント`(탈것), `ミニオン`(꼬마 친구), `エモート`(감정 표현), `トライヨラ`(툴라이욜라).

## 2. 주요 제외 항목 및 사유

| 제외 유형 | 대표 제외 예시 | 제외 이유 |
| --- | --- | --- |
| **일반 동사/명사 과치환** | `捨てる`(멀리서 처리하는 장판), `落ちる`(로그아웃), `メイン`(메인 퀘스트), `ツアー`(마물런), `カード`(점성 카드), `タイタン`(타이탄 장판), `はい`/`いいえ`/`また`/`さて`/`制限`/`解除`/`処理`/`方法` | 일반 채팅·시스템 메시지에서 심각한 오역 유발 |
| **사전 해설문 / 메타 설명** | `まごころライン`, `タケノコ`, `カータ`, `カータライズ`, `エオイべ`, `おまけコーナー`, `インスタント`, `フレ`, `メン`, `被り`, `ギスギス`, `人数を示す予兆` | 용어 번역이 아니라 장문 해설이라 번역문을 망가뜨림 |
| **과번역 / 원문 없는 사과** | `レディチェ忘れました`, `回線落ちしました`, `ブルスクでした`, `もう埋まりました`, `様子見`(상황 보고서), `ペロる`(낼름낼름) | 원문에 없는 "죄송합니다" 추가 또는 오역 |
| **구분 파괴 / 모호 약어** | `D1`·`D2`→근딜, `D3`, `D4`, `H1`, `H2`, `IN`, `EW`, `AA`, `AW`, `MW`, `PW`, `RW`, `ZW`, `ID`, `リス` | 포지션 정보 손실 또는 일반 영단어/확장팩 약어 충돌 |
| **줄바꿈/예시 파싱 오류** | `ドマ式麻雀`→괜찮습니다, `グランドカンパニー`→총사령부 의뢰, `リーヴ`→총사령부 의뢰, `アドベンチャラー`→어드벤쳐 플레이트, `初見です`→초행입니다, 잘 부탁드립니다 | 원본 문서 줄바꿈·쉼표·메모로 원문과 번역이 어긋남 |
| **문장형 채팅** | `🟡소통` 및 `🟠모집` 장문 문장들 (`ご説明ありがとうです` 등) | 용어집이 아닌 SFT 병렬 문장(`community_phrases.jsonl`)으로 분리 관리 |
