### 1.2 목적함수 및 학습 결과

- **학습 궤적 (`848s` / 14.1분)**:
  - `pref_loss`: `2.5688 → 1.1314`, `margin`: **`-0.7217 → +0.1715`** (`+0.893` nats/token), `pref_acc`: `0.0% → 64.3%`.

## 3. 정성 검수 결과 (`a50 Q8_0` & `a50 imatrix Q5_K_M`)

1. **일반 다국어 24건 (`0 / 24` 회귀)**:
   - `a50 Q8_0`은 기준 `4B v0.2 lw84-100`과 **20 / 24건이 문자 단위로 완전 일치**했으며, 나머지 4건(`#02`, `#11`, `#12`, `#14`)도 전부 동등하거나 더 자연스러운 표현(`잠시 자리를 비우겠습니다. 5분 후에 돌아오겠습니다.`, `그 말이 맞네요. 그럼 B를 선택해 봅시다.`)이었다.
   - `a50 imatrix Q5_K_M` 역시 `DE->KO #15/#17`, `FR->KO #18/#19/#20`, `KO->JA #21/#22`, `KO->EN #23/#24`(`I'm all set. You can start right now.`) 전 항목이 완벽히 보존되었다.
2. **Hold-out 장문 (`5ddb5185`) 품질 향상**:
   - `a50 Q8_0`: `이곳은 비공정 착륙장과 모험가 길드, 그리고 꼭대기에 있는 제독의 관제실이 있습니다. 제독은 이곳에서 로민사 하늘과 땅, 바다를 감시하고 있지요.`
   - `a50 imatrix Q5_K_M`: `이곳은 비공정 착륙장과 모험가 길드, 그리고 꼭대기에 있는 제독의 관제실이 있습니다. 제독은 이곳에서 로민사 하늘과 땅과 바다를 감시하고 있지요.`
   - 기존 `v0.2`의 직역투(`공중, 육지, 해양`)가 자연스러운 한국어(`하늘과 땅, 바다`)로 개선되었다.
3. **고어체 `~소서` 분류기 보강**:
   - `a50`이 `Style: 고어체`에서 `부디 모래의 집으로 빨리 돌아가소서.`를 생성했는데, 기존 `korean_style.py`가 `소서`를 `하오체`로 분류하던 버그를 발견해 `RE_ARCHAIC`로 이동하고 단위 테스트를 추가했다.
4. **CPO 강도(`alpha`) 스윕의 중요성**:
   - `a100`은 3에폭 CPO 델타가 과도해 Distractor(`1/25`)와 Gate 6 루프(`1`)가 발생했으나, **`a50` (`0.50`)**에서는 안정성·일반 다국어·장문 충실도·5개 화계 100%·고어체 개선까지 **전 항목 무손실 파레토 개선**을 달성했다.
