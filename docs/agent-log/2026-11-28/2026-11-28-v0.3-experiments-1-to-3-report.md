# Ironworks Translator `v0.3` 모델 개선 실험 1~3 결과 리포트

- **작성일**: 2026-11-28
- **로드맵 문서**: `docs/agent-log/2026-11-28/2026-11-28-v0.3-model-improvement-roadmap.md`
- **실험 범위**: 실험 1 (`imatrix` 양자화 + Layer-wise Alpha 병합), 실험 2 (동일 원문 다중 화계 대조쌍 SFT), 실험 3 (`Context:` 조건부 번역 + Gate 6 검증)
- **공통 평가 프로토콜**:
  - 모든 지표는 **실제 양자화 GGUF + `llama-server.exe`**에서 Step 0 고정 디코딩(`temperature=0.0, top_k=1, repeat_penalty=1.0, frequency_penalty=0.30, repeat_last_n=16`)으로 산출.
  - 수정된 채점기(`tools/milmmt-dataset-builder/eval_gguf.py`, `tools/milmmt-glossary-builder/korean_style.py`) 기준 통일.
  - **안정성 우선 보고**: 모든 표에서 안정성 실패(루프·언어 드리프트·빈 출력·잘림·태그 누수)와 분모를 먼저 표기하고, 일반 다국어 24건 및 주요 Hold-out/Gate 6 출력을 전수 정성 검수함.

## 2. 실험 1 — 재학습 없는 품질 극대화 (`imatrix` 양자화 + Layer-wise Alpha 병합)

### 2.1 설정
- **캘리브레이션 코퍼스 (`calib_ffxiv.txt`)**: `val_sft.jsonl` (`600`건) + 다국어 리플레이 (`400`건) = `1,000`건 (`236,980 bytes`, 평가셋과 완전 격리). `llama-imatrix.exe`로 `1B`/`4B` 각각의 `imatrix.dat` 생성.
- **Layer-wise Alpha 병합**: Gemma-3 디코더 레이어 깊이 `l ∈ [0, L-1]`에 따라 LoRA `alpha`를 선형 증가 (`0.84 -> 1.00`, 평균 `0.92`; `1B`는 `0.80 -> 1.00`도 비교). 하위 레이어의 다국어 표현은 보수적으로 보존하고, 출력 화계·어미를 결정하는 상위 레이어에 LoRA 비중을 집중.

### 2.3 핵심 해석
1. **`4B lw84-100 Q8_0`의 순수 승리**: 평균 LoRA 강도는 기존 `a92`와 동일(`0.92`)하지만, 하위 레이어 `0.84`로 다국어 안정성을 지키고 상위 레이어 `1.00`으로 어미 제어를 강화해 `하십시오체 10/10`, `하게체 10/10`, `반말 9/10`, `애교 9/10`, `하오체 9/10`을 달성했고 일반 24건 회귀도 `0/24`(단순 어휘 차 3건)였다.
2. **`4B imatrix Q5_K_M`의 실전 가치**: `Q4_K_M`은 4-bit 정밀도 한계 때문에 `imatrix`를 적용해도 `해라체`/`반말` 감쇠를 막지 못했으나, `Q5_K_M + imatrix`는 `2.64 GiB`(`Q4` 대비 +324 MiB, `Q8` 대비 -1.21 GiB)로 **`65/80 (81.2%)`**을 달성해 `Q8_0 (66/80)`과 사실상 동급이다. 향후 `4B` 경량 배포본으로 `Q4_K_M` 대신 `imatrix Q5_K_M`이 압도적으로 유리하다.
3. **`1B` Layer-wise 한계**: 1B는 26레이어 소형 모델이라 상위 레이어 `1.00`이 `DE->KO` 같은 저빈도 방향의 어휘 보존에 민감했다.

## 3. 실험 2 — 동일 원문 다중 화계 대조쌍(Minimal-Pair) + 정제 라벨 SFT (`1B`)

- **원문 격리 선별**: `ffxiv-datamining` 공식 영어 대사 중 `eval.jsonl` 및 `eval_suite.py`와 5-gram 중복이 없는 일상/퀘스트 대사 `420`건 선별.

### 3.3 정성 검수 및 교훈
- **가설 강력 입증**: 단 `2,126`건의 동일 원문 다중 화계 대조쌍만으로 `1B`의 화계 제어율이 **`53.8% → 67.5~70.0%` (+13.7~16.2%p)** 도약했다. 특히 `"Thank you..."` 같은 영어 공손문에서 반말·애교 전환을 못 하던 고질병(`반말 2→8/10`, `애교 4→8/10`)이 극적으로 해결되었다.

## 4. 실험 3 — 직전 문맥(`Context:`) 조건부 번역 + Gate 6 검증 (`1B`)

### 4.1 1:1 무오염 `Context:` 학습 축(Axis 5) 구축
- 초기 추출에서 FFXIV 영어 로컬라이제이션 특유의 의역(transcreation, 예: 실프족 대사의 EN↔KO 문장 불일치)을 확인하고 즉시 폐기했다.
- 대신 아래 3종으로 **100% 1:1 의미 정합 `3,087`건**을 구축했다:
  1. **`JA->KO` 공식 연속 퀘스트 대사 `2,200`건**: 동일 퀘스트 인접 행에서 길이·의미 정합을 통과한 쌍 (`1,540` 관련 문맥 + `660` 무관 Distractor 문맥).
  2. **`EN->KO` 12B 역번역 연속 대사 `647`건**: 공식 한국어 연속 퀘스트 쌍을 `MiLMMT-46-12B-v1.0.Q4_K_M`으로 영어 역번역해 EN 의역 드리프트가 `0`인 1:1 쌍 생성 (`452` 관련 + `195` Distractor).
  3. **반사실 문맥 해소 대조쌍 `240`건**: Gate 6 평가 단어(`bank`, `bat`, `spring`, `light`, `glasses`, `match`, `あつい`, `かける`)와 **100% 비중복**인 30개 다의어 문맥 대조쌍(`×2 × 4배 오버샘플링`).
- **학습 구성**: 실험 2 FFXIV `25,515`건 + Axis 5 `3,087`건 (`28,602`건) + **완전한 `5,000`건 일반 리플레이 (`replay_general_4b.jsonl`, `14.9%`)** = **`33,602`건** (`1,052` steps, `eval_loss=1.4054` — 역대 1B 최저, 28.7분, peak VRAM `5.89 GB`).

- **Distractor Context Rejection (`15` 프롬프트)**: 무관한 FFXIV 직전 대사를 넣었을 때 일상 원문 번역에 게임 용어가 `0`건 누수되는지 평가.
- **Tag Leak & Stability**: `Context:` / `Previous:` 태그 노출, 루프, 언어 드리프트 검사.

### 4.4 `Exp3 1B` 정성 검수에서 적발한 승격 차단 사유 (핵심 교훈)
1. **5,000건 리플레이의 효과 확인**: 실험 2에서 드리프트했던 일반 `#02`(`잠시 자리를 비웁니다`, `a85`/`a92`)와 `#13`(`곧 돌아올게요, 문 앞에 누군가가 있어요`, 전 병합)이 **완벽히 복구**되었다.
2. **그러나 `1B` 용량 + 리플레이 비율 저하(`14.9%`)로 신규 회귀 발생**:
   - `DE->KO #17` (`Entschuldigung, ich habe die Nachricht zu spät gesehen.`): `v0.2`의 `메시지를 늦게 보았습니다`가 `알게 된 시간이 늦었습니다` / `알람이 늦게 울렸습니다`로 변질.
   - `KO->JA #22` (`다음에 또 만나요`): 공손체(`また会いましょう`)가 반말(`また会おう` / `またね`)로 이동.
   - `KO->EN #24` (`저는 준비 끝났습니다. 바로 시작해도 괜찮아요.`): `a92`/`a100`에서 두 번째 문장을 누락하고 `I'm ready to go.`만 출력(`a85`, `lw84-100`은 2문장 유지). 이는 `Context:` 2문장 입력→1문장 출력 학습(`3,087`건)이 1B 모델에 **다문장 축약 편향**을 유도한 결과로 해석된다.
   - `eval.jsonl` 장문(`5ddb5185`): `a92`에서 `'해상부대'의 기지` 구문이 4회 반복되며 `Lominsan => 로민사`를 누락(`8/9`). 반면 `a85`는 정상 번역(`9/9`).
3. **모델 체급별 역할 분리의 명확한 근거**:
   - `1B`는 `Context:`를 `3,087`건 학습해도 희소 영어 동음이의어(`bank`, `bat`, `spring`, `glasses`) 해소 한계(`3/8` 쌍)와 다문장 회귀 리스크가 공존한다.
   - 반면 **`4B`는 `Context:`를 전혀 학습하지 않은 제로샷 상태에서도 `5/8` 쌍 (`13/16` 정성)을 풀고 `0/15` bleed를 달성**했다.
