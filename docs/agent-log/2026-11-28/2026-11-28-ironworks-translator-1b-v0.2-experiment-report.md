# Ironworks Translator 1B v0.2 (NPC Speech-Style + Glossary Conditioning) 실험 리포트

- **작성일**: 2026-11-28
- **대상 모델**: `sappho192/ironworks-translator-1b-v0.2` (기반: `xiaomi-research/MiLMMT-46-1B-v1.0`)
- **핵심 목표**: `4B v0.2`에서 검증된 1:1 역번역(`v0.2-r2`) 데이터셋과 6방향 일반 리플레이를 `1B` 모델에 동일 적용해, 경량 로컬 모델에서도 런타임 용어집(`Glossary:`)과 8화계 NPC 말투(`Style:`) 조건부 번역을 회귀 없이 제공하는 것.

## 1. 학습 구성 및 수렴 결과

- **기반 모델**: `xiaomi-research/MiLMMT-46-1B-v1.0` (1.01B params, trainable LoRA params `13,045,760`)
- **학습 데이터**: `v0.2-r2` `23,400`건(Axis 1 Glossary 9,600 / Axis 2 Chat 4,800 / Axis 4 Style 9,600 = 8화계×1,200) + 6방향 일반 리플레이 `5,000`건 = **총 `28,400`건 train / `600`건 val**
- **학습 설정**: 2 epochs (`888` steps), effective batch 64 (`batch_size=4, grad_accum=16, gradient_checkpointing=True`), peak VRAM `4.05 GB`, 소요 시간 `39분 35초`
- **손실 수렴**: `first_loss=2.141 → final_loss=1.289`, **`eval_loss=1.419`** (`1B v0.1` `eval_loss=1.715` 대비 **-0.296 개선**)

### 2-2. `a100` 탈락 및 `a92` 선정 사유 (정성 검수)

정량 스타일 제어율은 `a100`이 `46/80`으로 더 높았으나, 실제 번역 출력 검수에서 다음 회귀가 확인되어 탈락했다:
- **DE→KO #17**: `"Entschuldigung, ich habe die Nachricht zu spät gesehen."`
  - `a92`: `"죄송합니다. 메시지를 늦게 보았습니다."` (정확)
  - `a100`: `"죄송합니다. 알람이 늦게 울렸습니다."` (단어 환각)
- **FR→KO #19**: `"Je reviens dans quelques minutes, ne bougez pas."`
  - `a92`: `"몇 분 후에 돌아올 테니 움직이지 마세요."` (정확)
  - `a100`: `"몇 분 후에 돌아올 테니 안 움직여."` (비문·어투 붕괴)
- **KO→EN #24**: `"저는 준비 끝났습니다. 바로 시작해도 괜찮아요."`
  - `a92`: `"I'm ready to go. You can start right now."` (정확)
  - `a100`: `"I'm ready to go."` (후속 문장 누락)
- **`eval.jsonl` 1건**: `a100`에서 `"airship landing"` → `"기상청"` 환각 발생, `a92`는 `9/9` 유지.

`4B v0.2`와 동일하게 **`alpha=0.92`**가 일반 다국어 번역 품질을 100% 보존하면서 스타일 제어와 용어집 추종력을 극대화하는 Pareto 최적점으로 확인되었다.
